Washgo is a webapp for car owners to book car washes. It will be used in Vietnam's marketplace, so both english and vietnam options should be provided. 

User Onboarding
1. User chooses between the different plans
    - Basic: 50 tokens 
    - Premium: 100 tokens 
    **tokens will be used as currency in the marketplace 

Marketplace
1. User is able to view all available CarWash shops in the area through 
    - quick view 
    - search up locations 

Booking and Purchasing Slots
1. User chooses a CarWash shop 
2. User inputs date, time and necessary details 
3. User can customise the services they want (eg, exterior, interior, etc)
4. At the end of the page, the total cost will be in terms of tokens

Claiming free car washes: 
1. (Following from above) After confirming the booking and making the payment via tokens, journey card will be updated to increase by one stamp 
2. When 5 stamps have been collected, users are given 1 free car wash voucher to be used anywhere
